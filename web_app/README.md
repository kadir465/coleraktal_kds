# Web App Dizini (Web App Directory) Dokümantasyonu

Bu dizin, Flask web uygulamasının daha önceki bir yinelemesini veya alternatif bir sürümünü içerir. Esas olarak kullanıcı arayüzünün ilk geliştirme ve prototipleme aşamalarında kullanılmıştır.

## Kullanım ve Bağlam

Bu dizin kullanıcı arayüzü tasarımı ve yerel test paradigmaları hakkında tarihsel bir bağlam sağlasa da, aktif üretim kod tabanı (production codebase) değildir. Hugging Face Spaces ile tam entegrasyonu, Docker konteynerizasyonunu ve Gemini API'sini içeren mevcut, buluta hazır sürüm için lütfen kesinlikle `KDS_Deploy` dizinine başvurun.

Dağıtım (deployment) boru hattını (pipeline) etkilemeden yerel arayüz değişiklikleri ile denemeler yapmak isteyen geliştiriciler, bu dizin içerisinde `python app.py` komutunu kullanabilirler.
